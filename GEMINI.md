# RoamSEO

This extension connects Gemini CLI to the hosted RoamSEO MCP server (https://app.roamseo.com/mcp). The first RoamSEO tool call opens an OAuth sign-in; there is no API key to set.

Use the RoamSEO tools when the user asks about keywords, competitors, site audits, rankings, backlinks, Google Search Console or Analytics data, or how a brand appears in AI answers.

- Base advice on RoamSEO data for the user's site, not on generic SEO tips.
- Some tools spend RoamSEO credits. Before a large or repeated batch, tell the user what it will cost and ask first.
- To test the connection for free, check the connection and list the user's projects.

Step-by-step workflows for these tasks (audits, keyword research, clustering, local SEO, reports and more) live in `plugins/roamseo/skills/` in this extension.

Docs: https://roamseo.com/docs/mcp
